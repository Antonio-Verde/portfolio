## Web and business applications

| Project | Focus | Case study |
| --- | --- | --- |
| **Authentico** | Commercial quote configurator | [Explore the project](progetti/authentico.md) |
| **Palcoscenico Dancewear** | E-commerce experience for individual customers, dance schools and retailers | [Explore the project](progetti/palcoscenico.md) |

**Palcoscenico Dancewear** combines a product catalog, variant selection, size guidance and a shopping cart. It supports individual purchases and the needs of dance schools and retailers. The project is in development.

## My approach

I start with the task a person needs to complete and define the data and actions required to support it. For AI features, I use explicit schemas and tool boundaries, preserve source information where relevant and distinguish implemented behavior from measured performance.

Project source code is kept in private repositories.
